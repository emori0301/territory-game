# BGMファイルの配置

このフォルダにRPG風のBGMファイル（`rpg-bgm.mp3`）を配置してください。

## 推奨フリー音源サイト

- [魔王魂](https://maoudamashii.jokersounds.com/)
- [DOVA-SYNDROME](https://dova-s.jp/)
- [フリーBGM素材](https://www.free-bgm.com/)
- [MusMus](http://musmus.main.jp/)

## ファイル名

`rpg-bgm.mp3` として配置してください。

## 注意事項

- ループ可能な音楽を選択してください
- ファイルサイズが大きすぎないように注意してください（推奨: 1-3MB）
- MP3形式を推奨します

# 地形画像の配置

このフォルダにRPG風の地形画像を配置してください。

## 必要な画像ファイル

以下の画像ファイルを配置してください：

- `grass.png` - 草地（平地）
- `water.png` - 水
- `rock.png` - 岩（背景が透明または緑色のもの）
- `tree.png` - 木
- `swamp.png` - 沼地
- `mountain.png` - 山

## 推奨フリー素材サイト

- [OpenGameArt.org](https://opengameart.org/)
- [itch.io - Free Game Assets](https://itch.io/game-assets/free)
- [Kenney.nl](https://kenney.nl/assets)
- [Craftpix.net](https://craftpix.net/freebies/)

## 画像の要件

- サイズ: 32x32ピクセル推奨（または16x16、64x64）
- 形式: PNG（透明背景推奨）
- スタイル: RPG風、ドット絵風
- 岩の画像: 背景が透明または緑色のものを推奨（違和感なく表示されます）

## 注意事項

画像が配置されていない場合、フォールバックとして色とアイコンで地形が表示されます。
